What is jQuery? +
jQuery is a small JavaScript library. It makes it easy to select elements, handle events and create effects and animations.
How to include jQuery? +
Add a <script> tag with a link to the jQuery file from a CDN, for example https://code.jquery.com/jquery-3.7.1.min.js.
What are jQuery effects? +
Effects are ready methods like .hide(), .fadeIn() and .slideToggle().
What does .animate() do? +
.animate() changes CSS properties with numbers (width, left, opacity...) smoothly over time.
